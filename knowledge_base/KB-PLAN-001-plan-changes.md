# Scope
Use when a customer asks about changing their current plan.
# Verification checks
Confirm current plan and contract end date.
# Approved resolution
State the current plan and contract end date, then transfer the request to a human plan specialist because available plan options are not in this knowledge base.
# Escalation criteria
Transfer all plan-change requests requiring available options, pricing, or order completion.
