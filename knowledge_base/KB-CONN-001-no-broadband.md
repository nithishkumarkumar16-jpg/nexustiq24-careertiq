# Scope
Use for a broadband connection issue where no known area outage applies.
# Verification checks
Confirm whether all devices are affected and check the local outage status.
# Approved resolution
Ask whether all devices are affected if that fact is missing. For an all-device issue, advise checking router power and cable connections, then restarting the router once.
# Escalation criteria
Escalate if reboot, cable checks, and router reset have already been tried and service remains unavailable.
