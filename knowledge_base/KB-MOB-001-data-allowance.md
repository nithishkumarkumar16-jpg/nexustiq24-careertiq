# Scope
Use for questions about the current mobile data allowance or plan.
# Verification checks
Read the plan name and usage summary from the account record.
# Approved resolution
Explain the recorded plan and the recorded current-cycle usage only.
# Escalation criteria
Escalate if the customer disputes usage and the account has no supporting usage detail.
