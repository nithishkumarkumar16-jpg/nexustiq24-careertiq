# Scope
Use when prescribed connection checks are documented as already attempted and the issue persists.
# Verification checks
Review ticket history for router reboot, cable check, and router reset.
# Approved resolution
Do not repeat already completed troubleshooting.
# Escalation criteria
Transfer the case to network support with the issue, confirmed service status, and all recorded attempted steps.
